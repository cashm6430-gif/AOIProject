# 测量平台算法库（Algorithm SDK）开发需求文档  

本算法库用于工业测量平台，要求具备：插件化、可扩展、可调度、可复用、可测试、跨平台（Windows/Linux）等能力。

允许使用：

- Qt 的基础数据结构（QString、QVector、QImage、QJsonObject、QPluginLoader 等）

- Qt 插件机制（QPluginLoader / QFactoryLoader）

禁止使用：

- Qt UI 组件（QWidget、QML、Qt Quick 等）

## 1. 基础数据结构模块（geometry_core）

算法库必须提供独立的基础几何与数据结构模块，供所有算子共享。

### 1.1 基础几何类型

- 点（2D/3D）
- 线（2D/3D）
- 平面
- 圆/圆弧
- 坐标系（旋转 + 平移）
- 标定参数（相机内参、外参、畸变参数）

### 1.2 数学基础

- 使用 Eigen 作为矩阵/向量运算库

- 所有几何对象必须是轻量、可序列化的 POD 或简单结构体

## 2. 输入数据结构（支持 2D 图像 + 3D 点云）

算法库必须同时支持 2D 图像 和 3D 点云（含可选强度）。

### 2.1 2D 图像

- 使用 cv::Mat 或自定义轻量结构
- 支持灰度/彩色
- 支持 ROI、像素格式、通道数等元数据

### 2.2 3D 点云（PointCloud）

必须支持：
✔ 点云基本结构

```cpp
struct PointXYZ { float x, y, z; };
struct PointXYZI { float x, y, z, intensity; };
```

✔ 点云容器

```cpp
struct PointCloud {
    QVector<PointXYZ> points; // 或 QVector<PointXYZI>
    bool hasIntensity = false;
    int width = 0; int height = 0;
};
```

✔ 结构化点云（m×n）

- 保留行列结构
- 支持 float32 输入

## 3. 算子体系（Operator System）

算法库采用“模块 + 算子”的插件化架构。

### 3.1 算子（Operator）接口

算子是最小执行单元，必须满足：

```cpp
class IOperator {
public:
    virtual ~IOperator() = default;
    virtual QString name() const = 0;
    virtual void setParams(const QJsonObject& obj) = 0;
    virtual void execute(AlgorithmContext& ctx) = 0;
};
```

算子之间不直接调用，通过上下文传递数据。

### 3.2 算子分类

- 预处理算子：去噪、滤波、畸变矫正、ROI 裁剪、点云滤波等
- 特征提取算子：边缘、角点、直线、圆、点云平面/直线提取
- 几何计算算子：拟合直线/圆/平面、坐标变换
- 测量算子：距离、角度、形位公差
- 输出算子：OK/NG 判定、结果打包

## 4. 算子数据传递（AlgorithmContext）

算子之间的数据通过上下文传递，而不是直接调用。

```cpp
class AlgorithmContext {
public:
    template<typename T>
    void set(const QString& key, const T& value);

    template<typename T>
    T get(const QString& key) const;

    bool has(const QString& key) const;
private:
    QHash<QString, QVariant> data_;
};
```

支持：

- cv::Mat
- PointCloud
- 中间特征
- 几何结果
- 测量结果

## 5. 算子图（Operator Graph）与 Taskflow 调度

算法链由算子构成 DAG：

```
Undistort → GaussianBlur → Sobel → FitLine → ComputeDistance
```

Taskflow 用于：

- 分析算子依赖
- 构建 DAG
- 并行执行算子
- 自动调度

算子图由 JSON 配置描述。

## 6. 算法参数系统（JSON Schema + Versioning）

### 6.1 算子参数 JSON 化

每个算子必须支持：

- JSON 参数序列化
- JSON 参数反序列化
- 参数校验（schema）
- 参数版本号（version）

示例：

```json
{
  "type": "GaussianBlur",
  "version": 1,
  "params": {
    "kernel": 5,
    "sigma": 1.2
  }
}
```

### 6.2 算法链配置

整个算法链也必须可 JSON 化：

```json
{
  "pipeline": [
    { "id": "undistort", "operator": "Undistort", "params": {...}, "deps": [] },
    { "id": "blur", "operator": "GaussianBlur", "params": {...}, "deps": ["undistort"] }
  ]
}
```

## 7. 插件系统（Qt 插件机制）

算法库必须支持插件化扩展，使用 Qt 插件系统：

- 使用 QPluginLoader 加载 .dll/.so

- 插件必须导出一个工厂类

- 插件可注册多个算子

### 7.1 插件接口

```cpp
class IOperatorPlugin {
public:
    virtual ~IOperatorPlugin() = default;
    virtual QList<std::shared_ptr<IOperator>> createOperators() = 0;
};
Q_DECLARE_INTERFACE(IOperatorPlugin, "com.company.Algorithm.IOperatorPlugin/1.0")
```

### 7.2 插件加载

- 使用 QPluginLoader 动态加载
- 自动注册算子到 OperatorRegistry

## 8. OperatorRegistry（算子注册表）

```cpp
class OperatorRegistry {
public:
    void registerOperator(const QString& name, std::function<std::shared_ptr<IOperator>()> factory);
    std::shared_ptr<IOperator> create(const QString& name) const;
private:
    QHash<QString, std::function<std::shared_ptr<IOperator>()>> factories_;
};
```

## 9. AlgorithmTask（单工件算法执行引擎）

算法库不负责多工件调度，只负责单工件执行。

### 9.1 API

```cpp
class AlgorithmTask {
public:
    bool open();
    void close();

    void setInput(const AlgorithmInput& in);
    bool process();
    AlgorithmOutput getOutput() const;

    void setConfig(const QJsonObject& config);
};
```

### 9.2 输入输出结构

```cpp
struct AlgorithmInput {
    int workpieceId;
    QVector<QImage> images;
    QVector<PointCloud> pointclouds;
};

struct AlgorithmOutput {
    bool ok;
    QString reason;
};
```

## 10. 不使用 Qt UI

禁止使用：
- QWidget
- QML
- Qt Quick
- QGraphicsView
- 任何 UI 相关模块

允许使用：
- QtCore
- QtGui（仅用于 QImage）
- QtPlugin
- QtJson

## 11. 与上层调度系统的接口

算法库不负责多工件调度。

上层系统（如 Taskflow Pipeline）通过 AlgorithmTask 调用算法库：

```
Acquire → AlgorithmTask.process() → Output
```

算法库必须保持：

- 无全局状态
- 可多实例并行
- 可线程安全

## 📌 最终总结：算法库必须具备的能力

- 支持 2D 图像 + 3D 点云（含可选强度）
- 基础几何库（点线面坐标系）
- 插件化算子体系（Qt 插件机制）
- 模块化组织（Module）
- 算子图（Operator Graph）
- Taskflow 调度
- JSON 参数系统（schema + version）
- AlgorithmTask（单工件执行引擎）
- AlgorithmContext（数据总线）
- OperatorRegistry（算子注册表）
- 不使用 Qt UI
- 与上层调度完全解耦
