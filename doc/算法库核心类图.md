```cpp
+----------------------+
|      AlgorithmTask   |
+----------------------+
| - registry: OperatorRegistry&
| - graph: AlgorithmGraph
| - input: AlgorithmInput
| - output: AlgorithmOutput
| - config: QJsonObject
+----------------------+
| + open(): bool
| + close(): void
| + setInput(const AlgorithmInput&): void
| + setConfig(const QJsonObject&): void
| + process(): bool
| + getOutput() const: AlgorithmOutput
+----------------------+

+----------------------+
|    AlgorithmGraph    |
+----------------------+
| - nodes: QVector<OperatorNode>
+----------------------+
| + addNode(const OperatorNode&): void
| + execute(AlgorithmContext&): void
+----------------------+

+----------------------+
|     OperatorNode     |
+----------------------+
| - id: QString
| - op: QSharedPointer<IOperator>
| - predecessors: QVector<QString>
+----------------------+

+----------------------+
|      IOperator       |<<interface>>
+----------------------+
| + name() const: QString
| + setParams(const QJsonObject&): void
| + execute(AlgorithmContext&): void
+----------------------+

+----------------------+
|   AlgorithmContext   |
+----------------------+
| - data: QHash<QString, QVariant>
+----------------------+
| + set<T>(const QString&, const T&): void
| + get<T>(const QString&) const: T
| + has(const QString&) const: bool
+----------------------+

+----------------------+
|   OperatorRegistry   |
+----------------------+
| - factories: QHash<QString, Factory>
+----------------------+
| + registerOperator(const QString&, Factory): void
| + create(const QString&) const: QSharedPointer<IOperator>
+----------------------+

+----------------------+
|    IOperatorPlugin   |<<interface>>
+----------------------+
| + createOperators(): QList<QSharedPointer<IOperator>>
+----------------------+

```

关系：
AlgorithmTask → 使用 → AlgorithmGraph, OperatorRegistry, AlgorithmContext  
AlgorithmGraph → 包含 → OperatorNode → 持有 → IOperator  
OperatorRegistry → 创建 → IOperator  
IOperatorPlugin → 注册 → IOperator 到 OperatorRegistry
